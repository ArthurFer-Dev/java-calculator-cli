# Java Calculator CLI

Projeto de calculadora em Java executado no terminal.

## Objetivo
Praticar lógica de programação, organização de código e versionamento com GitHub.

## Funcionalidades
- Operações matemáticas básicas
- Validação de entrada do usuário
- Tratamento de erro
- Estrutura simples e organizada

## Como executar

Compilar:

javac src/*.java

Executar:

java -cp src Main
